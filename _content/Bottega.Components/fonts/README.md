# Bundled Fonts

Nunito Latin variable fonts, normal and italic, support weights 200-900.
Source: `@fontsource-variable/nunito` version `5.2.7`, distributed via jsDelivr.

- https://cdn.jsdelivr.net/npm/@fontsource-variable/nunito@5.2.7/files/nunito-latin-wght-normal.woff2
- https://cdn.jsdelivr.net/npm/@fontsource-variable/nunito@5.2.7/files/nunito-latin-wght-italic.woff2

These files are served locally by Bottega.Components; visitors do not contact
Fontsource or jsDelivr. See OFL.txt for the SIL Open Font License and attribution.
Characters outside the Latin subset can use the CSS fallback fonts.
